                                         # Salary Prediction Using Machine Learning
   ## Project Overview

This project predicts an estimated salary based on years of work experience using Machine Learning. A Linear Regression model is used to learn the relationship between experience and salary.

   ## Features
- Displays a preview of the dataset.
- Shows basic dataset information.
- Predicts salary based on years of experience.
- Displays a graph showing the relationship between experience and salary.

   ## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

   ## Machine Learning Algorithm
Linear Regression

   ## How to Run the Project
Install the required Python libraries:
    py -m pip install streamlit pandas numpy scikit-learn matplotlib

Run the application:
    py -m streamlit run app.py
  ##  Project Purpose
This project was developed as part of a Machine Learning assignment to understand data preprocessing, model training, salary prediction, and data visualization.
